Tiempo: 1 semana Grado 11.º · Tecnología I.E. Pepito Pérez · Santa Marta

Aplicarás métricas de evaluación como precisión y sensibilidad para medir la efectividad de una Inteligencia Artificial.

Objetivo

Comprender, aplicar y proponer procesos de entrenamiento de modelos de Machine Learning, tomando como base un conjunto de datos (dataset) al cual aplicar algoritmos, métricas de evaluación y técnicas de optimización para garantizar predicciones precisas y éticas.

Pregunta Esencial

Si el entrenamiento de modelos de Machine Learning permite que la tecnología "aprenda" a identificar patrones complejos, ¿qué ventajas o desventajas traería para el desarrollo humano el que nunca se hubiera descubierto la forma de entrenar algoritmos, obligándonos a depender únicamente de la programación tradicional basada en reglas fijas?

Desempeños

  • Comprende la lógica de los algoritmos de entrenamiento y la importancia de la división de datos (Entrenamiento/Testeo).
  • Aplica procesos de entrenamiento a un modelo de ML usando herramientas como Teachable Machine, validando con métricas de precisión y sensibilidad.
  • Compara el comportamiento de un modelo ante datos nuevos, identificando Sobreajuste vs. Subajuste.
  • Propone y diseña ajustes en los parámetros de entrenamiento para optimizar la respuesta del modelo.
  • Argumenta con sentido crítico el impacto de los sesgos en el entrenamiento de modelos y la transparencia algorítmica.

Las Reglas del Juego: ¿Cómo aprende una IA?

Para que un modelo aprenda correctamente, seguimos una estructura lógica. No es solo "lanzar datos", es seguir estas reglas:

El Dataset (Los Apuntes)

Es la información histórica. Se divide en Entrenamiento (para estudiar) y Testeo (para el examen final).

El Algoritmo (La Estrategia)

Es el método que usa la IA para encontrar patrones. ¿Buscamos tendencias o clasificamos imágenes?

La Evaluación (La Nota)

Usamos métricas como la Precisión para saber si la IA está aprendiendo o solo memorizando.

La Optimización (El Ajuste)

Si la IA falla, "ajustamos las tuercas" de la fórmula matemática para que falle menos la próxima vez.

Ejemplo de lógica: Si Modelo identifica Perro → Y es realmente un Gato → Error aumenta → Optimizar parámetros. Es decir: si la IA se equivoca, el sistema calcula qué tan lejos estuvo de la verdad y ajusta sus reglas internas para no repetir el error.

Componentes Clave que Transforman tu Modelo

Tasa de Aprendizaje (Learning Rate)

Define qué tan rápido aprende la IA. Si es muy alta, la IA "salta" las conclusiones; si es muy baja, tardará siglos. Es como el acelerador de un carro.

Número de Épocas (Epochs)

Es la cantidad de veces que la IA lee el conjunto de datos completo. Muchas épocas pueden causar Sobreajuste; pocas pueden causar Subajuste.

Capacidad del Modelo

Define qué tan complejo es el cerebro de la IA. Un modelo con mucha capacidad puede memorizar en lugar de aprender si el problema es simple.

Función de Pérdida (Loss Function)

Es el "termómetro" del error. Le dice a la máquina qué tan lejos está de la respuesta correcta. Entre más pequeña sea la pérdida, mejor es el modelo.

El Mapa de Conceptos

Para dominar el entrenamiento de una IA, recuerda esta tabla comparativa de las etapas:

Etapa del Proceso Ejemplo Práctico Uso en el Modelo ¿Cuándo usarlo?
Entrenamiento Estudiar 100 fotos de gatos. Usar el 80% del Dataset. Para que la IA busque patrones y aprenda reglas.
Prueba (Testeo) Examen con 20 fotos nuevas. Usar el 20% del Dataset. Para verificar si la IA realmente aprendió o solo memorizó.
Optimización Ajustar el tiempo de estudio. Modificar la Tasa de Aprendizaje. Cuando el error es muy alto y necesitamos que la IA mejore.

Taller: "Entrenando mi Primer Clasificador"

Diseñarás la lógica para un modelo que diferencie "Correos Deseados" de "Correos Basura (Spam)".

Fase 1
Preparación del Dataset
  • Recolección: Imagina que tienes 1,000 correos. ¿Cuántos usarás para Entrenamiento y cuántos para Prueba?
  • Etiquetado: ¿Qué palabras clave crees que el algoritmo debería identificar como "Atributos" de un correo Spam? (Ej: "Ganaste", "Premio", "Dinero").
Fase 2
Configuración del Cerebro
  • Épocas: Si tu modelo tiene un error muy alto en la práctica, ¿deberías aumentar o disminuir el número de veces que repasa los datos?
  • Tasa de Aprendizaje: Si la IA está tomando decisiones muy "alocadas" y no se estabiliza, ¿qué ajuste le harías al acelerador (Learning Rate)?
Fase 3
Reto de Innovación — Fake News

Situación: Tu modelo de detección de Spam ahora debe funcionar para detectar noticias falsas (Fake News) sobre salud. ¿Qué cambio técnico harías en tu entrenamiento para que la IA sea más "estricta" y no deje pasar información peligrosa? Escribe tu propuesta.

Situación
IA para la Convivencia Escolar

La tendencia en tecnología es usar IA para detectar el Ciberbullying en redes sociales antes de que cause daño. Si tuvieras que entrenar un modelo para analizar mensajes del chat del colegio, responde:

  • ¿Qué datos de entrenamiento propondrías? ¿Qué tipo de frases debería "leer" la IA para diferenciar un chiste de un insulto?
  • ¿Cómo usarías las Métricas de Evaluación (Precisión y Sensibilidad)? ¿Qué es más grave: que la IA ignore un insulto real o que bloquee un mensaje amistoso por error?
  • Explica de qué manera este modelo mejora la seguridad de los estudiantes.

Reflexión Crítica

  • ¿Por qué es peligroso que una IA se entrene solo con un tipo de datos (por ejemplo, solo con fotos de personas de un solo país)?
  • ¿Qué fue lo más "mágico" o sorprendente de entender que una máquina no nace inteligente, sino que nosotros la "educamos" con datos?
  • ¿Lograste diferenciar por qué la IA a veces "memoriza" en lugar de "aprender"? (SÍ / NO)
