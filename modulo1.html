Sesión 1: De los Bloques al Código — Intro a MicroPython

Tiempo: 1 semana Grado 11.º · Tecnología I.E. Pepito Pérez · Santa Marta

Al finalizar esta guía, serás capaz de traducir la lógica visual de bloques a instrucciones reales en MicroPython. Comprenderás cómo "hablarle" a la Micro:bit mediante texto para crear mensajes dinámicos y animaciones, logrando que una simple tarjeta se convierta en una herramienta de comunicación para tu comunidad.

Objetivo

Capacitar al estudiante en la transición de la programación visual por bloques al lenguaje textual MicroPython, permitiéndole comprender la sintaxis básica y la lógica de control necesaria para interactuar con el hardware de la Micro:bit de manera autónoma.

Pregunta Esencial

Si los bloques son las piezas de construcción, el código es la materia prima: ¿De qué manera el paso de una programación visual a una textual amplía las posibilidades de crear soluciones tecnológicas más precisas y personalizadas para las necesidades de nuestra comunidad?

Desempeños

  • Traduce la lógica de programación visual (bloques) a la sintaxis textual de MicroPython.
  • Construye programas básicos usando display y sleep para interactuar con el hardware.
  • Analiza la eficiencia del código frente a los bloques, identificando las ventajas de Python.
  • Propone soluciones tecnológicas usando la pantalla LED de la Micro:bit para comunicar ideas sociales.
  • Evalúa su propio proceso de aprendizaje identificando errores y proponiendo correcciones.

Contenido: Las Reglas del Juego (Sintaxis Básica)

Para que la Micro:bit no se confunda, debemos seguir una estructura clara. Observa este ejemplo de un "Hola Mundo" técnico:

MicroPython — Hola Mundo python.microbit.org 
from microbit import *     # 1. Importar la librería

while True:                   # 2. Bucle infinito
    display.scroll("Hola!")  # 3. Mostrar mensaje
    sleep(1000)               # 4. Esperar 1 segundo
1
Importar librería

from microbit import * — carga todas las funciones de la Micro:bit.

2
Bucle infinito

while True: — el código se repite para siempre (como el latido del corazón).

3
Salida en pantalla

display.scroll() desplaza texto. display.show() muestra un ícono o imagen.

4
Pausa

sleep(ms) — pausa el programa en milisegundos. sleep(1000) = 1 segundo.

¿Qué pasa si escribes Display.Scroll con mayúsculas? ¡La Micro:bit no lo entendería! La precisión en el texto es más importante que en los bloques. Python distingue MAYÚSCULAS de minúsculas.

El Traductor Humano

Escribe un código que simule un "Latido de Corazón".

Código del Latido 
from microbit import *
while True:
    display.show(Image.HEART)
    sleep(500)
    display.show(Image.HEART_SMALL)
    sleep(500)

Rúbrica de Evaluación
